Este repositório contém projetos e atividades desenvolvidos durante a especialização em Inteligência Artificial na UTFPR, cobrindo desde estatística básica até Deep Learning.

🚀 Projetos Principais
Autoencoders (Visão Computacional): Redução de dimensionalidade e reconstrução de imagens usando o dataset Fashion MNIST com Keras/TensorFlow.

Séries Temporais (TDNN): Predição de temperatura mínima diária utilizando redes neurais com retardo de tempo (Time Delay Neural Network).

Classificação & Spam: Comparação de algoritmos (KNN, SVM, Árvores de Decisão e Regressão Logística) para detecção de spam.

Otimização de Modelos: Uso de GridSearchCV e validação cruzada para ajuste de hiperparâmetros em redes MLP.

Regressão Avançada: Estimativa de preços de imóveis (House Sales) com análise de perda (loss) e correlação de atributos.

Estatística Aplicada: Análise de dados de saúde com cálculo de desvio-padrão e Teste ANOVA para comparação de grupos.

🛠 Tecnologias
Linguagem: Python

Bibliotecas: Scikit-Learn, TensorFlow/Keras, Pandas, NumPy, Matplotlib e SciPy.
